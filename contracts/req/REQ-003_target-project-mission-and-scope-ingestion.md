# REQ-003 Contract: Target Project Mission and Scope Ingestion

Status: Implemented  
Requirement ID: `REQ-003`  
Owner surface: `scripts/strategy_context_sweep.py`

## Purpose

Strategy context sweep must ingest target project mission/scope as authoritative base constraints for recommendation generation.

This contract rejects incomplete mission/scope input using explicit reason codes and does not allow fallback inference.

## Input Contract

Accepted payload shape:

```json
{
  "target_project": {
    "mission": "string or {\"text\": \"...\", \"source\": \"...\"}",
    "scope": "string or {\"text\": \"...\", \"source\": \"...\"}"
  }
}
```

Rules:

1. `target_project` must be an object.
2. `target_project.mission` is required.
3. `target_project.scope` is required.
4. Each anchor may be:
   - non-empty string, or
   - object with required non-empty `text` and optional string `source`.
5. Empty strings are rejected.
6. Missing mission/scope is rejected.

## Rejection Reason Codes

Explicit reason codes emitted by ingestion:

- `invalid_payload_type`
- `target_project_missing`
- `target_project_invalid_type`
- `mission_missing`
- `mission_invalid_type`
- `mission_text_missing`
- `mission_empty`
- `mission_source_invalid_type`
- `scope_missing`
- `scope_invalid_type`
- `scope_text_missing`
- `scope_empty`
- `scope_source_invalid_type`

## Output Contract

Success output:

```json
{
  "ok": true,
  "reason_codes": [],
  "target_project_constraints": {
    "mission": {
      "text": "string",
      "source": "string",
      "authoritative": true
    },
    "scope": {
      "text": "string",
      "source": "string",
      "authoritative": true
    }
  },
  "recommendation_generation": {
    "base_constraints_source": "target_project_mission_scope",
    "authoritative_fields": ["mission", "scope"]
  }
}
```

Failure output:

```json
{
  "ok": false,
  "reason_codes": ["..."],
  "errors": [
    {
      "reason_code": "...",
      "message": "human-readable reason"
    }
  ]
}
```
