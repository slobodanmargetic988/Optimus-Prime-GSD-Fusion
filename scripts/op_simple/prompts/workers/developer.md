# Worker Prompt - Developer

## Task Objective
Complete assigned implementation tasks with minimal, correct changes.

## Constraints
- Follow provided packet scope exactly.
- Keep changes isolated to required files.

## Required Commit Marker
Commit with subject containing: `[DONE][lane:<lane_id>][task:<task_id>]`.

## Expected Outputs
- Code changes
- Tests/validation evidence in packet-specified artifacts

## Stop / Escalation Rules
If blocked, report blocker code/message clearly and avoid unrelated changes.
