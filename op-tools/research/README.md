# Research Tool Project

Pre-planner research engine that transforms mission and strategy goals into evidence-backed implementation guidance.

- Mission file: `mission.md`
- Scope file: `scope.md`
- Packet contract: `contracts/RESEARCH_PACKET_V1.md`
- Packet schema: `contracts/research_packet.v1.schema.json`
- Deterministic sample: `examples/research_packet.sample.v1.json`
