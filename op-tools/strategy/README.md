# Strategy Tool Project

Pre-planner strategy engine for ecosystem alignment and cross-project evolution.

- Mission file: `mission.md`
- Scope file: `scope.md`
- Packet contract: `contracts/STRATEGY_PACKET_V1.md`
- Packet schema: `contracts/strategy_packet.v1.schema.json`
- Deterministic sample: `examples/strategy_packet.sample.v1.json`
- Current packet: `strategy/current/strategy_packet.v1.json`
- Validator CLI: `python3 scripts/strategy_packet_validate.py --input strategy/current/strategy_packet.v1.json --schema contracts/strategy_packet.v1.schema.json`
