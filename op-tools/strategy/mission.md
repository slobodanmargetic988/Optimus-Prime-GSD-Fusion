# Mission: Strategy Tool

Build a pre-planner strategy engine that runs before planning and continuously aligns each project with ecosystem-level direction.

This tool is responsible for strategic coherence, not implementation. It must convert high-level mission intent into versioned strategy artifacts that explain where the project sits in the Earth portfolio, what changed since the last strategy revision, and what strategic adjustments should happen next.

The strategy output should help planners create better tasks by making cross-project value explicit. A feature should not be proposed only because it can be built; it should be proposed because it strengthens both the local project and the larger ecosystem architecture, telemetry quality, and long-term maintainability.

When operating at Earth root, Strategy becomes ecosystem steward:
- tracks portfolio evolution and strategic drift
- identifies over-invested and under-invested areas
- proposes rebalancing actions and synergy opportunities
- surfaces strategic debt that can block future velocity

The mission succeeds when every planner run can point to an explicit, current strategic context, and when strategy history shows deliberate evolution over time rather than random directional change.
