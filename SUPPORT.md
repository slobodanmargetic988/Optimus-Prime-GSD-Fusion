# Support

Start with the [desktop setup guide](desktop/README.md) or the
[command-line troubleshooting guide](docs/install/TROUBLESHOOTING.md).

For bugs and feature requests, use
[GitHub Issues](https://github.com/slobodanmargetic988/Optimus-Prime-GSD-Fusion/issues).
The repository is public and community contributions are welcome. Include your app and provider CLI versions, operating system and a
small reproducible example. Redact credentials and private project content before
sharing diagnostic output. See [SECURITY.md](SECURITY.md) for sensitive reports.

Optimus is free and community-supported. Your AI provider manages its own
authentication, usage limits and billing; check the provider's account tools for
those questions. A detected CLI does not confirm account access or quota.

[Sponsor Optimus on GitHub](https://github.com/sponsors/slobodanmargetic988) if you
would like to support development. Sponsorship is voluntary and does not unlock
features or guarantee a support response time. Contributions of code,
documentation and testing are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md).
